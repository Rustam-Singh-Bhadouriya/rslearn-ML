# 📊 rslearn.metrics

This module provides essential `regression` & `classification` evaluation metrics implemented from scratch using NumPy.

Currently, it includes:  
**Regression Tools**  
- **R² Score (`r2_score`)**
- **Mean Squared Error (`mse`)**
- **Mean Absolute Error (`mse`)** 
- **Root Mean Squared Error (`rmse`)**

**Classification Tools**  
- **Accuracy Score (`accuracy_score`)**
- **Confusion Metrics (`confusion_metrics`)**
- **Recall (`recall`)**
- **Precision (`precision`)** 
- **F1 Score (`f1_score`)**
