## Setup
Before starting setuping the environment is Important  
```bash
pip install rslearn-py==1.0.4
```
or
```
pip install --upgrade rslearn-py
```

**Preferred Environment**
* Virtual Environment
* Linux Bash System (if possible not mandantory)
* Numpy, Pandas, Kagglehub installed
